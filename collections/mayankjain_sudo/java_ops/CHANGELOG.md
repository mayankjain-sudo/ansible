# Changelog

## 1.0.0

- Download ZIP and TAR.GZ Java bundles from a user-supplied complete HTTP(S) URL.
- Safely inspect and extract bundles, selecting nested JAR/WAR deployables by
  their archive-relative path.
- Add versioned deployment, checksum verification, health checks, automatic
  recovery, explicit rollback, and optional release retention.
- Add collection usage and configuration documentation.
